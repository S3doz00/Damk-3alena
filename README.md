# Damk 3alena

A graduation team project exploring how hospitals and blood donors in Jordan can coordinate demand, availability, and donation campaigns. The repository contains a donor mobile app, hospital dashboard, shared data layer, and an AI service prototype.

## What the prototype covers

- Donor registration, eligibility, appointments, and campaign discovery in a React Native app.
- Hospital workflows and demand views in a React dashboard.
- Weekly demand forecasting, shortage alerts, and donor recommendation logic in a FastAPI service.
- Supabase/PostgreSQL for application data and authentication.

The forecasting work uses XGBoost quantile regression. The project is a prototype and should not be treated as a clinically validated system.
